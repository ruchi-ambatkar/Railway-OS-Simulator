Producer–Consumer includes the railway train and bounded-buffer animation, individual produce/consume actions, and independent Auto Producer / Auto Consumer controls. Memory Management has distinct Fixed and Variable Partitioning modes.

Memory Management defaults: fixed mode uses four equal 256 KB partitions; variable mode allocates the default requests (130, 250, 100, 115 KB) into dynamically sized blocks.
